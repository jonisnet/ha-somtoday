# Somtoday Login Helper downloaden

Download de nieuwste kant-en-klare versie:

**[Somtoday Login Helper 0.1.2 (ZIP)](Somtoday-Login-Helper-0.1.2.zip)**

Pak de ZIP volledig uit en dubbelklik daarna op
`INSTALLEREN-WINDOWS.cmd`. De installer opent de juiste extensiepagina en de
map die je moet kiezen. De complete uitleg staat ook in
`LEESMIJ-EERST.txt` in de ZIP.

Chrome en Edge staan de directe installatie van een extensie buiten hun eigen
webwinkel niet toe. Daarom moet **Ontwikkelaarsmodus** één keer worden aangezet
en moet de uitgepakte map één keer worden gekozen.
